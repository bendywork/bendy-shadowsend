# 全局页面优化方案（REQ-202609-0071）

> 需求：全局页面 UI 优化。用户反馈整体不够细腻精致、缺少 macOS 质感；登录页过于浮夸不简洁；聊天界面偏乱。
> 约束：代码部署在 Vercel（环境变量已配置），本地只读代码 + 本地临时验收；基于 git worktree 开发，用完可删、代码保留。

## 一、现状评估

技术栈：Next.js 16 (App Router) + React 19 + Tailwind CSS v4（CSS-first，`@theme inline`）+ lucide-react。主题走 CSS 变量 + `:root[data-theme="light"]`。

问题清单：

1. **设计令牌单薄、缺体系**（`src/app/globals.css`）
   - 只有一层背景/边框/文字变量，没有分层的表面色（surface）、统一圆角、统一阴影、统一间距标度。
   - 强调色是灰色 `#71717a`，暗色主题几乎无品牌感，谈不上"精致"。

2. **日间主题靠 `!important` 硬补**（globals.css 98-151 行）
   - 用一堆 `:root[data-theme="light"] .bg-black`、`.bg-black\/65` 等选择器逐个覆盖暗色工具类，极其脆弱：新增一个暗色类就漏一处，日间就花。这是"不细腻"的根因之一。

3. **登录页浮夸**（`src/app/page.tsx`）
   - 打字机动画 + 双径向渐变光斑 + `text-5xl` 巨标题 + `tracking-[0.28em]` 全大写标签 + 脉冲光标，信息噪声大。
   - 圆角混用（`rounded-3xl/2xl/xl/lg`），聚焦态仅 `focus:ring`（弱），输入框/按钮层级不清。

4. **聊天页是 2804 行单文件巨石组件**（`src/app/room/[roomCode]/page.tsx`）
   - 房间树、成员、公告、广告位、上传、二维码、图片查看器全塞一个文件，样式内联散落，视觉密度高、留白不足 → "乱"。

5. **字体无 macOS 系统字体**：`--font-sans` 只有雅黑/苹方，缺 `-apple-system`/`SF Pro`，Mac 上看不出原生质感。

## 二、优化目标（macOS 质感）

克制、精致、统一。要点：中性偏冷的分层表面色、`-apple-system` 字体栈、统一 8px 圆角家族、柔和多层阴影、清晰聚焦环、毛玻璃(vibrancy)克制使用、动效轻量。

## 三、实施范围（本轮）

分阶段、小步推进，本轮聚焦"地基 + 第一印象"，聊天页深度重构列为后续阶段。

- [x] **P1 设计体系**：重写 `globals.css`——分层 surface 变量、统一圆角/阴影/聚焦环、`-apple-system` 字体栈、精修滚动条与选中态；日间主题改为语义变量驱动，尽量去掉逐类 `!important` 硬补。
- [x] **P2 登录页**（`page.tsx`）：降噪——收敛标题层级与间距、统一圆角、精修输入/按钮/分段控件、保留但克制毛玻璃卡片；去掉过度动画的浮夸感。
- [x] **P3 聊天页安全皮肤化**：聊天页自动继承新设计体系（系统字体、精修滚动条、聚焦环、日间主题重制、克制背景）；主发送按钮改为 accent 主按钮（`.btn-primary`），与登录页统一。不动逻辑与数据流。
- [ ] **P4（后续）** 聊天页 2804 行单文件组件化拆分与深度重排（顶栏/成员/公告/气泡的结构化重构），需单独排期与本地联调。
