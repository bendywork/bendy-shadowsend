# 右侧成员栏设计规范（ui-10）

> 需求：REQ-202610-0473「右侧成员栏重构」阶段二
> 组件：`src/components/chat/member-panel.tsx`
> 依赖：设计令牌（REQ-202610-0464）、`.segmented` / `.chip` / `.menu-*` / `.icon-btn` 组件类

## 1. 信息层级

成员栏按「栏目标题 → 汇总 → 视图切换 → 成员卡片」四层组织，避免标题、人数与操作在同一行争抢注意力。

| 层级 | 内容 | 视觉处理 |
| --- | --- | --- |
| 栏目标题 | 「成员管理」/「成员列表」 | 11px、字距 `0.16em`、`text-ink-faint` |
| 汇总 | `N 人 · M 在线` | 14px 半粗、`text-ink` |
| 视图切换 | 成员 / 审批（仅房主） | `.segmented`，两等分，带数量徽标 |
| 成员卡片 | 头像 + 昵称 + 角色 + 在线 + 最近活跃 | `bg-panel/60`、`rounded-xl`、12px 内边距 |

标题右侧只保留两个图标入口：房主「房间设置」与「收起成员栏」。设置入口与 ui-25 设置抽屉（当前为 `Popover`）衔接，点击后由页面打开设置面板，成员栏本身不持有设置状态。

## 2. 成员卡片

### 2.1 结构

- 头像：36px；右下角 10px 在线点，`border-canvas` 形成挖空效果。
- 昵称：单行截断，`text-sm font-medium text-ink`。
- 角色：`.chip`，房主带 `Crown` 图标，普通成员带 `Users` 图标。
- 状态行：在线 / 离线 + 最近活跃相对时间，11px。
- 操作菜单：仅房主可见，且只出现在非房主成员卡片上；菜单项为「房主转让」「移除房间」，移除项使用 `menu-item--danger`。

### 2.2 在线口径

在线状态统一使用 `ONLINE_WINDOW_MS`（2 分钟），与后端 `/api/presence` 保持一致：

- `lastSeenAt` 缺失或非法 → 离线。
- `now - lastSeenAt <= 2 分钟` → 在线（含边界）。
- 时钟漂移导致的未来时间 → 在线，最近活跃显示「刚刚」。

最近活跃文案由 `describeLastActive()` 归一为 `justNow / minutes / hours / days / never`，再由 i18n 拼接，组件内不硬编码中文。

### 2.3 状态与交互

- 卡片 hover 使用 `bg-elevated/50`，只过渡颜色，不改变尺寸。
- 菜单按钮具备 `aria-haspopup="menu"`、`aria-expanded`；点击外部或 `Esc` 关闭，关闭后焦点回到触发按钮。
- 转让/移除进行中，菜单项禁用并显示 `LoaderCircle`，防止重复提交。
- 房主本人卡片不显示操作菜单，避免自我转让/移除。

## 3. 审批流

- 审批卡片与成员卡片共用圆角、底色与内边距，形成同一视觉族。
- 头部：头像 + 昵称 + 「申请于 {time}」；有申请理由时以浅色引用块展示，最多两行。
- 操作区：通过（`.btn-primary`）与拒绝（`.btn-secondary`）等宽并排，高度与 `.btn-sm` 一致。
- 处理中：两个按钮同时禁用，当前动作显示旋转图标，并通过 `aria-busy` 暴露状态。
- 空状态：圆形图标容器 + 主文案 + 一句说明，不使用空白卡片。

## 4. 可访问性

- 房主视图使用 `role="tablist"` / `role="tab"` / `role="tabpanel"`，Tab 与面板通过 `aria-controls` / `aria-labelledby` 关联。
- 非房主视图不渲染 Tab，成员列表使用 `aria-label="成员列表"`。
- 所有纯图标按钮都有 `aria-label`，并配合 `Tooltip`。
- 状态不只依赖颜色：在线/离线同时有文字，角色同时有文字与图标。
- 菜单支持键盘打开（Enter/Space）、`Esc` 关闭与焦点归还。

## 5. 响应式

- 右侧栏在 `xl` 断点宽度为 320px（原 290px），为角色徽标与操作按钮留出余量。
- 成员栏收起后网格降为两列；折叠状态由 `usePersistentBoolean("tb:members-collapsed")` 持久化。
- 小于 `xl` 时成员栏位于聊天区下方，最大高度 56vh，内部列表独立滚动。
