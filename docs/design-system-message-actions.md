# 长消息折叠与复制交互（REQ-202610-0485 / ui-22）

## 目标

在现有消息气泡上补齐长消息的可读性与操作反馈：更早折叠、预览不切断语义、展开有动效、复制成功/失败都有就地反馈。

## 折叠规则

实现集中在 `src/lib/message-collapse.ts`，页面只消费纯函数结果：

| 规则 | 取值 |
| --- | --- |
| 字符阈值 | 超过 600 字符 |
| 行数阈值 | 超过 12 行 |
| 字符预览窗口 | 240–420 字符（约为正文 35%，再夹取到窗口内） |
| 行预览 | 前 8 行 |

- 字符与行数任一超限即折叠，覆盖长段落与「很多短行」的代码/日志。
- 预览优先在段落空行处截断，其次换行、句末标点（。！？!?；;…）、空白，最后才按字符截断。
- 截断点会避开 UTF-16 代理对，不会把 emoji 切成乱码。
- 折叠按钮的 `title` / `aria-label` 提示「剩余 N 字」，让用户知道展开成本。

## 展开动效

- 展开/收起时正文以 `opacity` + `translateY(4px)` 做 180ms 入场，不改变宽高、边距或定位，避免触发布局。
- 仅用户点击展开/收起时播放；消息首次渲染不播放入场动画。
- `prefers-reduced-motion: reduce` 下关闭动画。

## 复制反馈

- `src/lib/clipboard.ts` 统一复制入口：优先 `navigator.clipboard.writeText`，失败后回退到 `textarea + document.execCommand("copy")`。
- 成功：按钮切换为对勾 +「已复制」，Toast 同步提示；2 秒后恢复。
- 失败：按钮切换为 X +「复制失败」并显示危险色，Toast 提示检查浏览器权限；2 秒后恢复。
- 按钮文本包在 `aria-live="polite"` 中，屏幕阅读器可获知状态变化。
- 邀请链接复制也复用同一入口，保证反馈一致。

## 可访问性

- 折叠按钮使用 `aria-expanded` 与 `aria-controls` 关联正文 `id`。
- 复制按钮的 `aria-label` / `title` 随状态变化。
- 所有新增图标均为 `aria-hidden`，状态由可见文本承载。

## 测试

- `src/lib/message-collapse.test.ts`：10 条用例覆盖字符/行数阈值、预览窗口、段落/句末/空白边界、emoji 代理对、行预览。
- `src/lib/clipboard.test.ts`：5 条用例覆盖异步剪贴板、execCommand 回退、无 API、异常清理与空文本。
- `npm test`：5 个测试文件 39 条全部通过。

## 验收清单

- [x] 600 字以内且不超过 12 行的消息不折叠。
- [x] 超限消息显示预览与「展开全文」，展开后显示全文。
- [x] 展开/收起有轻量动效，reduced-motion 下关闭。
- [x] 复制成功/失败均有按钮态与 Toast 双重反馈。
- [x] 非安全上下文可通过 execCommand 回退完成复制。
