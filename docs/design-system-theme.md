# 双主题规范（Dark / Light）

> 适用版本：v0.1.69（REQ-202610-0501 / ui-38，双主题回归）
> 目标：深色为默认主题，浅色只重映射设计令牌；全页面不出现主题专用选择器、`!important` 覆写或逐组件反色补丁。

## 1. 架构与边界

主题体系分三层，组件只能消费语义令牌：

1. **Primitive ramp**：10 级中性灰（`--ds-gray-0` … `--ds-gray-9`，0 = 画布，9 = 墨色）。
2. **Semantic tokens**：`--ds-surface-*`、`--ds-line-*`、`--ds-ink-*`、`--ds-action-*`、`--ds-*-soft/border`、`--ds-qr-*`。
3. **Theme mapping**：`:root` 为深色默认；`:root[data-theme="light"]` 只覆盖 primitive ramp 与少量由 ramp 派生、需要单独校准的令牌。

硬性约束：

- `globals.css` 中禁止出现 `!important`。
- 浅色主题块内禁止出现 `.bg-*` / `.text-*` / `.border-*` 工具类覆写，也禁止 `--color-*` 映射覆写；只允许 `--ds-*` 令牌。
- 组件不得硬编码颜色值，也不得写 `[data-theme="light"] &` 一类的局部反色；需要新颜色时先加语义令牌。
- 主操作保持反色：深色主题白底黑字，浅色主题黑底白字。
- 切换主题只改变 `<html data-theme>`；`color-scheme` 随主题切换，保证原生控件、滚动条与表单自动适配。

主题偏好的读写：

- 存储键：`localStorage["tb:theme"]`，值为 `dark` | `light`，缺省 `dark`。
- `src/app/layout.tsx` 的 `PREHYDRATION_INIT` 在首帧绘制前同步 `data-theme` 与 `lang`，避免闪白/闪黑。
- `ThemeToggle` 使用 `useSyncExternalStore` 订阅偏好，服务端快照固定为 `dark`，避免水合不匹配。

## 2. 令牌与对比度基线

### 2.1 基础表面与文字

| 令牌 | 深色 | 浅色 | 用途 |
| --- | --- | --- | --- |
| `--ds-surface-canvas` | `#08080a` | `#f4f4f6` | 页面画布 |
| `--ds-surface-panel` | `#101014` | `#ffffff` | 侧栏 / 面板 |
| `--ds-surface-card` | `#16161a` | `#fbfbfc` | 卡片 / 气泡 |
| `--ds-ink` | `#f5f5f7` | `#111113` | 主文字 |
| `--ds-ink-soft` | `#c9c9d0` | `#56565e` | 次级文字 |
| `--ds-ink-muted` | `#8e8e98` | `#5f5f67` | 辅助文字 |
| `--ds-ink-faint` | `#85858f` | `#6b6b74` | 最弱文字（仍须 ≥ 4.5:1） |
| `--ds-line-control` | `#6e6e78` | `#8a8a92` | 输入框/按钮边界（≥ 3:1） |

实测对比度（WCAG 2.1，普通文本要求 ≥ 4.5:1，UI 边界要求 ≥ 3:1）：

| 主题 | `ink` | `ink-soft` | `ink-muted` | `ink-faint` | `line-control` |
| --- | --- | --- | --- | --- | --- |
| 深色 · canvas | 18.38 | 12.15 | 6.17 | 5.48 | 3.97 |
| 深色 · panel | 17.43 | 11.52 | 5.85 | 5.20 | 3.76 |
| 深色 · card | 16.57 | 10.95 | 5.56 | 4.94 | 3.58 |
| 浅色 · canvas | 17.17 | 6.62 | 5.76 | 4.80 | 3.12 |
| 浅色 · panel | 18.86 | 7.27 | 6.33 | 5.28 | 3.43 |
| 浅色 · card | 18.24 | 7.03 | 6.12 | 5.10 | 3.31 |

说明：浅色 `--ds-ink-muted` / `--ds-ink-faint` 不能直接沿用深色 ramp 的 `--ds-gray-7`（对浅色画布仅 3.33:1 / 2.20:1），必须使用上表的显式值。弱文字禁止用 `opacity` 或 `color-mix(... transparent)` 生成，否则实际对比度会随背景漂移。

### 2.2 状态色

状态色是系统中唯一的彩色，只用于成功 / 警告 / 危险语义。

| 令牌 | 深色 | 浅色 | 浅色 soft 背景上的对比度 |
| --- | --- | --- | --- |
| `--ds-success` | `#30d158` | `#166f31` | 4.96 |
| `--ds-warning` | `#ffd60a` | `#855800` | 4.89 |
| `--ds-danger` | `#ff453a` | `#c11f2b` | 4.73 |

浅色 soft 背景为对应状态色 9%–10% 透明叠加画布。深色状态色在 14% soft 背景上的对比度分别为 8.10 / 10.84 / 5.18。

### 2.3 焦点环

| 主题 | 值 | 对画布对比度 |
| --- | --- | --- |
| 深色 | `color-mix(in srgb, #f5f5f7 55%, transparent)` | 5.81 |
| 浅色 | `rgb(17 17 19 / 0.55)` | 4.07 |

焦点环对相邻画布须 ≥ 3:1；浅色主题原先 0.42 透明度仅 2.72:1，已提高到 0.55。

## 3. 二维码专项

二维码在两种主题下都必须保持“白底黑码”，不跟随主题反色，否则相机识别率下降。

- 令牌：`--ds-qr-surface: #ffffff`、`--ds-qr-border: #d4d4d8`、`--ds-qr-dark: #111113`、`--ds-qr-light: #ffffff`。
- 容器：`.qr-frame` 固定白底、1px 边框、内边距 8px、圆角 16px；`img` 使用 `object-fit: contain` 与 `image-rendering: pixelated`。
- 颜色解析：`src/lib/qr-theme.ts` 的 `resolveQrThemeColors()` 从计算样式读取令牌；令牌缺失、非法或对比度低于 `QR_MIN_CONTRAST = 7` 时回退到默认黑/白。
- 当前二维码前景/背景对比度为 **18.86:1**，远高于 7:1 的内部阈值。
- 二维码图片带本地化 `alt`，关闭按钮带 `aria-label`。

## 4. 头像前景

头像背景来自用户色池（9 种灰阶）。`src/lib/avatar.ts` 的 `resolveAvatarForeground()` 按背景相对亮度在 `#111113` 与 `#ffffff` 中选择对比度更高者，保证每个色池颜色上的首字母 ≥ 4.5:1；非法颜色返回 `null`，由 CSS 的 `--ds-avatar-fg` 兜底。

## 7. 新增令牌 / 组件的规则

1. 先判断能否复用现有语义令牌；不能复用才新增 `--ds-*`。
2. 新令牌必须同时在 `:root` 与 `:root[data-theme="light"]` 中定义，或在浅色块显式覆盖。
3. 在 `@theme inline` 中登记 Tailwind 映射（如 `--color-*: var(--ds-*)`），组件只使用映射后的工具类。
4. 在 `src/lib/theme.test.ts` 增加对比度断言；文本 ≥ 4.5:1，边界/焦点 ≥ 3:1，二维码 ≥ 7:1。
5. 更新本文件的令牌表与对比度矩阵。
