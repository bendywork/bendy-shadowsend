# 移动端触摸与手势交互规范（v0.1.69 / REQ-202610-0747 / ui-47）

> 适用范围：房间页移动端（`< 1280px`）。与 ui-11（抽屉重构）、ui-20（图片查看器重构）、ui-39（响应式断点）联动验收。

## 1. 设计原则

1. **手势是增强，不是唯一入口**：所有手势操作都有可见按钮或键盘等价路径。
2. **纵向滚动优先**：任何手势判定先排除纵向位移，避免与页面滚动冲突。
3. **只动 `transform` / `translate` / `opacity`**：抽屉、操作面板、查看器入场与缩放均不触发布局。
4. **触控目标 ≥ 44×44 CSS px**：粗指针设备统一放大图标按钮、菜单项、分段控件与新增交互控件。
5. **尊重系统偏好**：`prefers-reduced-motion: reduce` 下关闭抽屉/查看器动画。

## 2. 手势契约

| 手势 | 判定 | 行为 |
| --- | --- | --- |
| 左边缘右滑 | 起点 `x ≤ 24px`，水平位移 ≥ 64px 或速度 ≥ 0.5px/ms，纵向漂移 ≤ 72px | 打开房间抽屉 |
| 右边缘左滑 | 起点 `x ≥ viewportWidth - 24px`，其余同上 | 打开成员抽屉 |
| 抽屉内反向滑 | 抽屉已打开，水平位移朝向对应边缘且达到阈值 | 关闭当前抽屉 |
| 长按消息 | 触屏/触控笔按住 450ms，位移 ≤ 12px | 打开消息操作面板 |
| 右键消息 | 桌面 `contextmenu` | 打开同一操作面板 |
| 双指缩放 | 两指距离比例 × 起始缩放，范围 1×–4× | 缩放图片，双指中点位移同步平移 |
| 单指拖拽 | 缩放 > 1× | 平移图片，边界按 contain-fit 尺寸钳制 |
| 双击 | 两次点击间隔 ≤ 300ms | 1× → 2.5×；已放大 → 复位 |
| 左右滑动切图 | 1× 状态，水平位移 ≥ 56px 或速度 ≥ 0.45px/ms，且纵向位移小于水平位移的 0.8 倍 | 上一张 / 下一张 |
| 键盘 | `←` / `→` / `+` / `-` / `0` / `Esc` | 切图 / 缩放 / 复位 / 关闭 |

阈值与纯函数位于 `src/lib/touch-gestures.ts`，对应单测 `src/lib/touch-gestures.test.ts`。

## 3. 组件与接入点

- `useEdgeSwipe`：窗口级单指触摸监听，仅在 `< 1280px` 生效；`enabled` 在弹层/查看器打开时关闭，避免手势穿透。
- `useLongPress`：返回 `onPointerDown/Move/Up/Cancel/Leave` 与 `onContextMenu`；触屏长按触发时短振动，并吞掉随后合成的 click，防止操作面板被立即关闭。
- `MessageActionSheet`：Portal 底部面板；复制文本、查看图片、下载附件、取消；焦点圈定、Esc/遮罩关闭、滚动锁定。
- `ImageViewer`：Portal 全屏查看器；图片列表由房间消息附件（`previewType === "IMAGE"`）派生，支持连续切换；下载按钮仅对服务端附件显示。
- 房间页抽屉：左右 `<aside>` 在移动端为 `fixed` 抽屉（`translate` 过渡），`xl` 断点恢复为静态三栏布局；遮罩层 `xl:hidden`。

## 4. 与联动需求的边界

- **ui-11**：若后续抽屉组件化，保留 `drawer-panel`、`data-open` 与 `translate-x-*` 契约，`useEdgeSwipe` 无需改动。
- **ui-20**：若后续替换查看器，保留 `ViewerImage` 数据结构与 `ImageViewer` props（`images` / `initialIndex` / `onClose` / `onDownload`）。
- **ui-39**：断点以 `xl = 1280px` 为桌面/移动分界；`useEdgeSwipe` 内部同样以 1280px 判定，避免断点漂移。

## 5. 验收清单

- [ ] 左/右边缘滑动可打开对应抽屉，反向滑动可关闭；纵向滚动不误触。
- [ ] 长按消息 450ms 打开操作面板；滚动或移动超过 12px 取消。
- [ ] 图片查看器双指缩放 1×–4×、放大后可拖拽且不越界、双击切换缩放、1× 时左右滑动切图。
- [ ] 所有新增控件在粗指针下 ≥ 44×44px。
- [ ] `Esc`、遮罩点击、关闭按钮均可退出弹层；关闭后焦点归还。
- [ ] `prefers-reduced-motion: reduce` 下无抽屉/查看器动画。
- [ ] `npm test`、`npm run lint`、`npx tsc --noEmit`、`npm run build` 全部通过。
